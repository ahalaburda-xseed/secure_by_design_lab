fastcolor

A tiny, dependency-free library for converting and manipulating colors. Hex, RGB, HSL, and named colors in under 3 KB.

Install

pip install fastcolor

Usage

from fastcolor import to_rgb
to_rgb("#ff8800")  # (255, 136, 0)

Why fastcolor?

  • Zero dependencies
  • Fully typed
  • MIT licensed
